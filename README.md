**`~/projects/home-designer`**

### AI House Planner

AI-assisted house planning application that generates editable 2D house floor plans from plot dimensions and room requirements.

**Stack** &nbsp;<code>React 19</code> <code>Vite</code> <code>TypeScript</code> <code>Tailwind CSS</code> <code>Zustand</code> <code>Framer Motion</code> <code>SVG</code> <code>NestJS</code>

**Key feature** — full floor-plan editor: drag/resize/rename rooms, place doors/windows/furniture, undo/redo, export to SVG, PNG, or PDF.

[Repository](https://github.com/sohealsayad/Home-Designer)
